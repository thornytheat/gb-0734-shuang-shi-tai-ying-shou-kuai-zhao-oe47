# 数据定义

## 变更文件

CSV 采用逗号和双引号，列顺序可变。整文件优先 UTF-8（含 BOM），回退 GB18030。每份收件按原字节 SHA-256 标识，最多 2 MiB 与 5000 条表头后记录。解析按逻辑记录迭代，记录物理起始行。零字节、仅空白、只有表头、断引号分别返回错误。单行列数错误、字段失效等行级问题隔离，其余继续。

| 字段 | 类型与规则 |
|---|---|
| `event_id` / `invoice_id` / `customer_id` | 不透明标识，保留前导零，1–64 位 ASCII 字母、数字、下划线、点和连字符 |
| `kind` | `VERSION`、`PAYMENT`、`REVERSAL` |
| `effective` | 有效始日或变动业务日，`YYYY-MM-DD` |
| `valid_to` | 版本独有，排除终日，空值表示无终点 |
| `known` | 有时区的 ISO 时间，精确到微秒；以 UTC 归一；工作台显示固定 UTC+08:00 |
| `due` | 版本必填，过期起算基准日 |
| `amount_cny` | 正金额，人民币元。空白、`-`、`N/A`、`NULL`、`未知` 为缺失；零值按无效金额隔离。支持全角和正确千分组；Decimal 转整数分后计算 |
| `ref` | 初版留空。修订版引用当前知识版本；收款或冲销引用已采信的原账面版本 |
| `note` | 原始备注，可含换行 |

同事件编号且同 UTC 知悉时刻的规范化副本只采信最早物理行；内容矛盾时隔离该时刻所有规范化候选。以后重复占用某个已可见事件编号时，仅隔离后来事件；历史截面保持原样。重复、空白、重复表头独立计数。

## 两个时间条件

- 版本业务区间 `[effective, valid_to)`；收款与冲销业务日 `<=` 有效切点。所有可见事件必须同时满足 `known <=` 知悉切点。
- 维持每张发票一位客户。分段版本可接续，新分段与已有有效区间冲突时保留已采信版本，同知悉时刻冲突的新分段同时隔离。显式修订只替换同发票、客户和业务区间的父版。父版的知悉区间在修订的知悉时刻排他结束；同刻多个候选亲缘修订都隔离。
- 收款和冲销在所选知识下从头按业务日、知悉时刻、类型、事件编号排序。原票未可见时进入待补，之后原票可见便可重算。允许引用已替换原版，原版须匹配发票和客户并且开始日不晚于变动日。变动当日和截面均需存在有效版本。可冲减上限为当日面额与截面面额的较小值减之前采信变动，超额整笔隔离。
- 同一发票的相邻版本描述累计债务池；采信的冲减在相邻有效版之间连续。没有活动版本的期末截面不显示该发票的余额；相关历史变动可在 `inactive` 中查看。

## 对账与归档

- 收件输入等于采信、解析隔离、重复、空白、重复表头之和。版本和业务隔离及待补是各个截面的裁决结果，单独统计。
- 逾期天数按业务有效日减到期日。到期当日仍未逾期。五桶为未逾期、1–30、31–60、61–90、91 天以上，已结清记录不入桶。
- 期间使用三次截面：期初、期初有效日与期末知悉截止、期末。第一步差为迟报回补。固定回补后余额按期末到期日迁移到期末桶，再记本期净变动；已退出发票按回补后到期日迁移后退场。迁移净额为零。
- 期初余额加面额净变动、减收款和冲销净变动，得到期末余额。各账龄桶按期初、迟报、迁移、本期到期末勾稽。入账净变动包含版本面额调整、新增和退出；有退出时面额、历史收款或冲销净变动可为负数。
- 归档编号取来源 SHA-256、规则版本与 UTC 化期间参数的摘要。在一个 SQLite 事务中提交清单、摘要和证据。重跑使用原始来源重新计算，逐字节校验且复用原归档。导出可复核来源隔离、各截面、逐票变化和账龄聚合。

## 核销备查登记

- 核销收回是独立于应收截面的备查簿，与归档共用一个 SQLite。核销、收回、再次核销三类凭证只增不改，按 `writeoff_id → recovery_id → rewriteoff_id` 逐级引用，逐笔可追溯。
- 核销登记按切点截面取数：核销前余额为该切点的发票应收余额；核销金额留空等于全额，否则不得超过账面余额。同一发票在同一来源内只建立一条核销链，后续变动经收回与再次核销登记；同一来源内核销凭证号唯一。
- 收回按银行回单勾稽：回单号在同一来源内是幂等键。同一回单重复报送返回原凭证且 `created=false`，不重复恢复；同号不同内容返回 409。收回金额不得超过核销链待收余额；查无核销记录的回单按正常收款流程处理，不在本簿登记。
- 再次核销引用收回凭证，金额不得超过该笔收回的未核销余额；凭证号在该笔收回内唯一，重复报送同样幂等。
- 收回后余额 ＝ 已核销金额 − 累计收回 ＋ 再次核销；客户合计为各核销链之和。对账校验：核销金额不超过核销前余额、累计收回不超过已核销金额、再次核销不超过累计收回。全部成立时状态为 `MATCHED`，任一不成立为 `DIFFERENCE`。
- 备查簿不改动应收截面：收回不恢复应收账款，已核销发票不因收回重回逾期名单或被重复催收；`open_ar_cents` 仅对照显示该发票在请求切点的账面余额。

当前适用于人民币、单文件来源和单一结算时区。多币种、时区自动推断、旧规则可执行包与变更流跨文件合并不在范围内。
